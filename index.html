Section 1. BOLDFACE Emergency Procedures
Emergency Engine Shutdown on the Ground
Correct Answer:PCL - OFF FIREWALL SHUTOFF HANDLE - PULL
Abort
Correct Answer:PCL - IDLE BRAKES - AS REQUIRED
Engine Failure Immediately After Takeoff (Sufficient Runway Remaining Straight Ahead)
Correct Answer:AIRSPEED - 110 KNOTS (MINIMUM) PCL - AS REQUIRED EMER LDG GR HANDLE - PULL (AS REQUIRED)
Engine Failure During Flight
Correct Answer:ZOOM/GLIDE - 125 KNOTS (MINIMUM) PCL - OFF INTERCEPT ELP
Immediate Airstart (PMU NORM)
Correct Answer:PCL - OFF STARTER SWITCH - AUTO/RESET PCL - IDLE, ABOVE 13% N1
Uncommanded Power Changes / Loss of Power / Uncommanded Propeller Feather
(left front console)
Correct Answer:PCL - MID RANGE PMU SWITCH - OFF PROP SYS CIRCUIT BREAKER (left front console) - PULL, IF Np STABLE BELOW 40%
Inadvertent Departure From Controlled Flight
Correct Answer:PCL - IDLE CONTROLS - NEUTRAL ALTITUDE - CHECK
Fire In Flight, If Fire is Confirmed:
Correct Answer:PCL - OFF FIREWALL SHUTOFF HANDLE - PULL
<32>PHYSIOLOGICAL SYMPTOMS
Correct Answer:BOS PUSH MAN - PRESS ON
<30>OBOGS Failure / Overtemp / Physiological Symptoms/<32>OXY CRIT Annunciator
Correct Answer:GREEN RING - PULL (AS REQUIRED) DESCENT BELOW 10,000 FEET MSL - INITIATE OBOGS SUPPLY LEVER - OFF (BOTH)
Eject
Correct Answer:EJECTION HANDLE - PULL
